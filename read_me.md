# AdaalAI — Pakistan Judicial AI/ML System ⚖️

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

AdaalAI is an AI and Machine Learning project designed to modernize Pakistan's judicial system. By automating routine legal paperwork, providing legal guidelines in Urdu, and helping judges prioritize their dockets, this system aims to help reduce the 2.2 million case backlog.

**Author:** Abdul Samad Satti 

## 🚀 Features

* **Urdu FIR Auto-Drafting:** A streamlined system to help citizens and police draft First Information Reports (FIRs) quickly and accurately using natural language processing.
* **Legal RAG Assistant:** An AI assistant that helps legal professionals quickly search past judgments and the Pakistan Penal Code (PPC).
* **Case Prioritization Model:** A machine learning model that scores and prioritizes cases based on urgency, age, and severity to optimize court scheduling.
* **Citizen Justice Chatbot:** A simple, accessible bot answering basic legal rights questions in Urdu.

## 🛠️ Tech Stack

* **Language:** Python
* **Machine Learning:** Scikit-Learn, XGBoost
* **NLP/AI:** LangChain, OpenAI API / Llama 3
* **Backend:** FastAPI
* **Database:** PostgreSQL (with pgvector for embeddings)
